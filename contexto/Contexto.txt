- **Base de datos local**: testinv

## Propósito
Este repositorio es la **plantilla base** desde la cual se clonan todos los
proyectos nuevos. No es un proyecto de producción en sí mismo.

El script `D:\www\scripts\crear.ps1` (v2.0) clona este repo desde GitHub,
genera el .env, ejecuta migraciones/seeders y deja el proyecto listo para
desarrollar.

## Historia
- crear2.ps1 / crear3.ps1: intentos anteriores de automatización (descartados)
- crear.ps1 v2.0: método actual — clonar desde GitHub y configurar
